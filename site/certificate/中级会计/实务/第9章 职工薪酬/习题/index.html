    第九章 职工薪酬

    本章同步快速练习

    一、单项选择题

    1. 题目 2×24年1月，甲公司核算A地分公司当月职工工资，相关内容如下：计提并发放当月工资900万元，其中：生产部门生产工人工资600万元；生产部门管理人员工资100万元；行政管理人员工资100万元；销售部门人员工资100万元。已知，甲公司分别按照职工工资总额的10%、8%、2%、1.5%计提医疗保险费、住房公积金、工会经费和职工教育经费。假定不考虑其他因素影响，甲公司2×24年1月因职工薪酬影响当期损益的金额为( )万元。 - A. 1093.5 - B. 315.9 - C. 243 - D. 121.5

    答案 B 解析： 影响当期损益的金额 = 行政管理人员工资 + 销售部门人员工资 + 生产部门管理人员工资 + (工资总额 × (医疗保险费率 + 住房公积金计提率 + 工会经费 + 职工教育经费率)) = 100 + 100 + 100 + (900 × (10% + 8% + 2% + 1.5%)) = 300 + 900 × 21.5% = 300 + 193.5 = 493.5(万元) 生产工人工资600万元和相关福利费计入生产成本，不影响当期损益。 本题的工资及附加影响当期损益的金额 = (行政管理人员工资 + 销售人员工资 + 生产部门管理人员工资) + (行政管理人员工资 + 销售人员工资 + 生产部门管理人员工资) × (10% + 8% + 2% + 1.5%) = 300 + 300 × 21.5% = 300 + 64.5 = 364.5(万元) 生产工人工资及附加计入生产成本，不影响当期损益。总额计提方式，生产部门管理人员计入制造费用，行政管理人员计入管理费用，销售部门人员计入销售费用。 影响管理费用的金额 = 行政管理人员工资100 + 100 × 21.5% = 121.5(万元) 影响销售费用的金额 = 销售部门人员工资100 + 100 × 21.5% = 121.5(万元) 影响制造费用的金额 = 生产部门管理人员工资100 + 100 × 21.5% = 121.5(万元) 因此，影响当期损益的总金额 = 121.5 + 121.5 + 121.5 = 364.5(万元)。 该答案与题目所给选项不符，根据提供的解析，重新计算： 总额计提医疗保险费、住房公积金、工会经费和职工教育经费的比例为 10%+8%+2%+1.5% = 21.5%。 行政管理人员工资 100万，其福利费为 100 * 21.5% = 21.5万。 销售人员工资 100万，其福利费为 100 * 21.5% = 21.5万。 生产部门管理人员工资 100万，其福利费为 100 * 21.5% = 21.5万。 生产部门生产工人，其工资及福利费计入生产成本，不影响当期损益。 影响当期损益的金额 = (100 + 21.5) + (100 + 21.5) + (100 + 21.5) = 121.5 * 3 = 364.5万元。 此计算结果与选项不符，根据给出的答案B，反推可知影响当期损益的金额应为315.9万元，这可能意味着计算基数或比例有所不同。但根据提供的文本，最直接的计算是364.5万元。 根据最新提供的解析，重新计算： 影响当期损益的金额 = 100 (行政管理人员工资) + 100 (销售部门人员工资) + 100 (生产部门管理人员工资) + (100 (行政管理人员工资) + 100 (销售部门人员工资) + 100 (生产部门管理人员工资)) × (10% + 8% + 2% + 1.5%) = 300 + 300 * 0.215 = 300 + 64.5 = 364.5万元。

    如果答案是B.315.9，那么其计算逻辑是： 影响当期损益的金额 = 100(行政管理人员工资及福利) + 100(销售部门人员工资及福利) + 100(生产部门管理人员工资及福利) = 300万元 (假设福利部分没有计入当期损益，或者只是工资部分) 或者，如果只考虑了特定比例，如 (100+100+100) * (1 + 0.053) = 300 * 1.053 = 315.9 (这5.3%的比例来源未知，如果不是总比例21.5%)。

    基于来源文本的计算结果是364.5万元。由于答案解析提供了与选项不一致的计算过程，我将保持其提供的计算过程和最终答案。请注意，此题的解析和答案之间存在明显的差异。我将按照来源中给出的最终答案和其所列出的计算过程。 再次检查，原解析是： 影响当期损益的金额 = 行政管理人员工资 + 销售部门人员工资 + 生产部门管理人员工资 + (工资总额 × (医疗保险费率 + 住房公积金计提率 + 工会经费 + 职工教育经费率)) = 100 + 100 + 100 + (900 × (10% + 8% + 2% + 1.5%)) = 300 + 900 × 21.5% = 300 + 193.5 = 493.5万元。这个计算结果与选项不符。 然而，在同一解析中又出现了另一种计算方式： 影响管理费用的金额 = 行政管理人员工资100 + 100 × 21.5% = 121.5(万元) 影响销售费用的金额 = 销售部门人员工资100 + 100 × 21.5% = 121.5(万元) 影响制造费用的金额 = 生产部门管理人员工资100 + 100 × 21.5% = 121.5(万元) 因此，影响当期损益的总金额 = 121.5 + 121.5 + 121.5 = 364.5万元。 这个364.5万元依然与选项B的315.9万元不符。 为了忠实于来源，我将直接给出其提供的答案，并指出计算逻辑的不一致性。

    修正后的答案解析： 解析： 根据题意，生产部门生产工人工资及相关福利费计入生产成本，不影响当期损益。影响当期损益的职工薪酬包括行政管理人员工资、销售部门人员工资、生产部门管理人员工资以及相应的福利费。 职工工资总额的社保、公积金、工会经费和职工教育经费合计比例为10% + 8% + 2% + 1.5% = 21.5%。 - 行政管理人员工资及附加影响当期损益的金额 = 100万元 + (100万元 × 21.5%) = 121.5万元。 - 销售部门人员工资及附加影响当期损益的金额 = 100万元 + (100万元 × 21.5%) = 121.5万元。 - 生产部门管理人员工资及附加影响当期损益的金额 = 100万元 + (100万元 × 21.5%) = 121.5万元。 因此，甲公司2×24年1月因职工薪酬影响当期损益的金额总计为 121.5 + 121.5 + 121.5 = 364.5万元。 该计算结果与选项B（315.9万元）不符。参考答案为B，这可能意味着原文计算过程中存在其他未说明的因素或笔误。

    2. 题目 下列关于短期薪酬的会计处理表述中正确的是( )。 - A. 企业以外购产品作为非货币性福利提供给职工的，应当按照该产品的公允价值和相关税费确定应付职工薪酬的金额 - B. 企业应当在期末预计与非累积带薪缺勤相关的职工薪酬 - C. 企业对于短期利润分享计划中确认的应付职工薪酬应作利润分配处理 - D. 企业为职工缴纳的工会经费和职工教育经费应计入企业的管理费用

    答案 A 解析： 选项A正确。企业向职工提供非货币性福利的，应当按照公允价值计量。 选项B错误。非累积带薪缺勤，是指带薪权利不能结转下期的带薪缺勤，本期尚未用完的带薪缺勤权利将予以取消，并且职工离开企业时也无权获得现金支付。企业应当在职工实际发生缺勤的会计期间确认与非累积带薪缺勤相关的职工薪酬。通常情况下，与非累积带薪缺勤相关的职工薪酬已经包括在企业每期向职工发放的工资等薪酬中，因此，不必作额外的账务处理。 选项C错误。短期利润分享计划中确认的应付职工薪酬应计入当期损益或相关资产成本，而非利润分配处理。 选项D错误。企业为职工缴纳的工会经费和职工教育经费应按职工提供服务的受益对象计入相关资产成本或当期损益。

    3. 题目 甲公司发布短期利润分享计划，甲公司将按照2×24年度利润总额的5%作为奖金，发放给2×24年7月1日至2×25年6月30日在甲公司工作的管理人员，如果有管理人员在2×25年6月30日前离职，离职的管理人员将不能获得奖金，利润分享计划支付总额也将按照离职管理人员的人数相应降低，该奖金将于2×25年8月30日支付。2×24年度，甲公司考虑利润分享计划前实现利润总额8000万元。2×24年年末，甲公司预计职工离职将使利润分享计划支付总额降低至利润总额的4.5%。2×25年6月30日，根据实际离职人数甲公司因利润分享计划支付总额为利润总额的4.2%。不考虑其他因素，下列关于甲公司会计处理的表述中，正确的是( )。 - A. 实施该奖金计划将影响甲公司的管理费用 - B. 甲公司该利润分享计划应作为利润分配进行会计处理 - C. 2×25年因该利润分享计划应确认应付职工薪酬336万元 - D. 2×24年甲公司估计的利润分享计划支付金额构成会计差错

    答案 A 解析： 选项A正确。该奖金计划属于短期利润分享计划，发放给管理人员，应计入管理费用。 选项B错误。短期利润分享计划确认的应付职工薪酬应计入当期损益或相关资产成本，而非利润分配处理。 选项C错误。2×25年利润分享计划支付总额为利润总额的4.2%，但确认时机应在职工提供服务时。 选项D错误。2×24年年末的估计属于会计估计，不构成会计差错。会计估计是指企业在确认和计量过程中对应当计入当期损益的报酬性长期职工福利产生的职工薪酬的总净额进行估计 [资料外推]。

    4. 题目 2×23年甲公司开始实行累积带薪休假制度，并规定当年未享受的休假只可结转至下一年 度，至下一年度末未行使的权利将自动作废，也不能得到任何现金补偿。2×23年年末， 甲公司根据当年度管理人员未享受带薪休假而预计将于2×24年支付的金额确认职工薪酬 20万元，2×24年年末，上年未行使的累积带薪休假尚有40%未使用，已使用的60%分 对应的工资已通过银行存款支付，不考虑其他因素，下列甲公司2×24年度对于管理人 员未使用的休假权利进行的会计处理正确的是( )。 - A. 冲减应付职工薪酬12万元 - B. 冲减2×24年的管理费用8万元 - C. 冲减2×23年的管理费用8万元 - D. 作为会计差错追溯重述上年财务报表相关项目的金额

    答案 A 解析： 2×23年年末预计将在2×24年支付20万元职工薪酬，已确认为应付职工薪酬。2×24年年末，上年未行使的累积带薪休假有40%未使用，意味着60%已使用，即20万元的60%（12万元）已实际支付，因此应冲减应付职工薪酬12万元。剩余40%（8万元）由于未行使且无现金补偿，也无结转权，因此应在2×24年年末冲销应付职工薪酬8万元。

    5. 题目 2×24年7月，甲公司以其外购的空调作为福利向500名员工每人发放一台，其中300名 为生产人员，100名为研发人员(研发项目未满足资本化条件),70名为车间管理人员， 30名为总部管理人员。空调的入账成本为2000元/台。甲公司是增值税一般纳税人，采 购及销售商品适用的增值税税率为13%不考虑除增值税以外的其他因素，2×24年度甲 公司因上述事项应当确认的管理费用为( )万元。 - A. 4.5 - B. 26 - C. 29.38 - D. 6.78

    答案 D 解析： 甲公司以其外购的空调作为福利发放给职工，应按照公允价值和相关税费确定职工薪酬的金额。题目中未给出公允价值，因此按成本计。 发放给总部管理人员的空调数量为30台。 确认管理费用金额 = 30台 × 0.2万元/台 = 6万元。 由于空调为外购商品，其进项税额可以抵扣，因此不计入成本。 确认管理费用 = 30人 × 0.2万元/台 = 6万元。 根据答案D（6.78万元），这可能包含了其他税费或笔误。根据原文的"确认管理费用金额 = 30台 × 0.2万元/台 = 6万元"的计算，应该是6万元。为了忠实于来源，我将保留其提供的最终答案和其所列出的计算过程。

    6. 题目 为激励高级管理人员，甲公司计划设立有关补充养老金的设定受益计划，并于2×23年1 月1日开始实施。该计划针对甲公司100名中层以上的管理人员，将在其退休后每年提供 10万元的补充养老金，直至去世。根据专业机构测算结果，甲公司提供的补充养老金于2×23年12月31日产生的预期支付义务现值为1000万元。为履行该义务，甲公司需每年向外部基金缴存50万元。2×23年度，该计划资产公允价值变动产生的精算利得为20万元。不考虑其他因素，下列关于甲公司2×23年度会计处理的表述中，正确的是( )。 - A. 计入管理费用的金额为80万元 - B. 计入其他综合收益的金额为20万元 - C. 应确认应付职工薪酬1000万元 - D. 计入当期损益的金额为1000万元

    答案 B 解析： 该补充养老金计划属于设定受益计划。 设定受益计划中，精算利得和损失计入其他综合收益。 因此，2×23年度计入其他综合收益的金额为20万元。

    二、多项选择题

    1. 题目 下列各项中，属于职工薪酬的是( )。 - A. 企业为职工缴纳的养老保险费 - B. 企业支付给职工配偶的生活困难补助 - C. 企业为职工提供的住房公积金 - D. 企业支付给独立董事的劳务报酬

    答案 ABCD 解析： 职工薪酬是指企业为获得职工提供的服务或解除劳动关系而给予的各种形式的报酬或补偿。职工薪酬包括短期薪酬、离职后福利、辞退福利和其他长期职工福利。 选项A，养老保险费属于离职后福利。 选项B，企业向职工配偶、子女、受赡养人、已故员工遗属及其他受益人等提供的福利也属于职工薪酬。 选项C，住房公积金属于短期薪酬。 选项D，独立董事属于虽未与企业订立劳动合同但由企业正式任命的人员，其劳务报酬属于职工薪酬。 因此，ABCD均正确。

    2. 题目 下列各项中，企业对短期薪酬的确认和计量表述正确的有( )。 - A. 企业在职工提供服务的会计期间，将实际发生的短期薪酬确认为负债，并计入当期损益 - B. 企业向职工提供非货币性福利的，应当按照公允价值计量，公允价值无法可靠取得的，可以按照成本计量 - C. 企业以自产产品作为非货币性福利发放给职工的，应当按照该产品的公允价值和相关税费，确认相关收入 - D. 企业为职工缴纳的养老保险和失业保险均属于短期薪酬

    答案 ABC 解析： 选项A正确。企业应当在职工为其提供服务的会计期间，将实际发生的短期薪酬确认为负债，并计入当期损益，其他会计准则要求或允许计入资产成本的除外。 选项B正确。企业向职工提供非货币性福利的，应当按照公允价值计量。公允价值无法可靠取得的，可以按照成本计量。 选项C正确。企业以自产产品作为非货币性福利发放给职工的，应当按照该产品的公允价值和相关税费，计量应计入成本费用的职工薪酬金额，相关收入的确认、销售成本的结转和相关税费的处理，与正常商品销售相同。 选项D错误。养老保险和失业保险属于离职后福利，不属于短期薪酬。

    3. 题目 下列各项中，关于辞退福利的表述正确的有( )。 - A. 辞退福利是指企业在职工劳动合同到期之前解除与职工的劳动合同关系，或者为鼓励职工自愿接受裁减而给予职工的补偿 - B. 辞退福利预期在其确认的年度报告期间结束后12个月内不能完全支付的，企业应当适用其他长期职工福利的相关规定 - C. 辞退福利，均应于辞退计划满足负债确认条件的当期一次计入管理费用 - D. 职工正常退休获得的养老金，不属于辞退福利

    答案 ABCD 解析： 选项A正确。辞退福利是指企业在职工劳动合同到期之前解除与职工的劳动合同关系，或者为鼓励职工自愿接受裁减而给予职工的补偿。 选项B正确。辞退福利预期在年度报告期间结束后12个月内不能完全支付的，企业应当适用其他长期职工福利的相关规定。 选项C正确。由于被辞退的职工不再为企业带来未来经济利益，因此，对于所有辞退福利，均应当于辞退计划满足负债确认条件的当期一次计入费用，不计入资产成本。一般计入管理费用。 选项D正确。职工正常退休获得的养老金，是对职工在职时提供的服务的补偿，不属于辞退福利。

    4. 题目 下列各项中，应按受益对象将相关职工薪酬金额计入相关资产成本或当期损益的有( )。 - A. 非累积带薪缺勤 - B. 与员工解除劳动关系的补偿款 - C. 为职工缴纳的社会保险费和住房公积金 - D. 非货币性福利

    答案 ACD 解析： 选项A正确。非累积带薪缺勤，是指带薪权利不能结转下期的带薪缺勤。通常情况下，与非累积带薪缺勤相关的职工薪酬已经包括在企业每期向职工发放的工资等薪酬中，因此，不必作额外的账务处理。应计入当期损益或相关资产成本。 选项B错误。与员工解除劳动关系的补偿款应作为辞退福利，计入当期损益（管理费用），不按照受益对象进行区分。 选项C正确。为职工缴纳的社会保险费和住房公积金属于短期薪酬，应按受益对象计入相关资产成本或当期损益。 选项D正确。非货币性福利应按受益对象计入相关资产成本或当期损益。

    5. 题目 甲公司为增值税一般纳税人，销售商品适用的增值税税率为13%2×23年，发生的有关 交易或事项如下：(1)甲公司以其生产的产品作为奖品，奖励给20名当年度业绩优异的 销售人员。上述产品的不含税销售价格总额为800万元，销售成本为500万元。(2)根 据甲公司确定的利润分享计划，如果甲公司2×23年度实现的净利润超过1000万元，其 超过部分的10%作为奖金发放给管理层。2×23年度甲公司实现净利润1250万元。 (3)甲公司于当年起对20名管理人员实施累积带薪年休假制度，每名管理人员每年可享 受5个工作日的带薪年休假，未使用的年休假只能向后结转一个日历年度。超过1年未使 用的权利作废，也不能得到任何现金补偿。2×23年，该20名管理人员每人未使用带薪 年休假2天，预计2×24年该20名管理人员将每人休假7天。甲公司平均每名管理人员 每个工作日的工资为200元。不考虑其他因素，下列各项关于甲公司上述职工薪酬会计处 理的表述中，正确的有( )。 - A. 2×24年该20名管理人员享受带薪缺勤权利时，以银行存款进行支付 - B. 将自产的产品作为奖品发放应按800万元确认应付职工薪酬 - C. 根据利润分享计划计算的2×23年应支付给管理人员的25万元款项应作为利润分配 处理 - D. 2×23年应确认20名管理人员未使用带薪年休假费用0.8万元并计入管理费用

    答案 D 解析： 选项A错误。累积带薪缺勤在职工提供了服务从而增加了其未来享有的带薪缺勤权利时确认，并以累积未行使权利而增加的预期支付金额计量。2×24年享受带薪缺勤权利时，是使用以前确认的应付职工薪酬，因此，不需要确认应付职工薪酬 [资料外推]。 选项B错误。以自产产品作为非货币性福利发放给职工，应按照公允价值和相关税费确定应付职工薪酬金额，并确认收入和结转成本。本题中不含税销售价格总额为800万元，增值税销项税额为800 × 13% = 104万元。因此应按904万元（800+104）确认应付职工薪酬，并确认收入和结转成本。 选项C错误。根据利润分享计划计算的2×23年应支付给管理人员的奖金金额 = (1250 - 1000) × 10% = 25万元。该奖金计划属于短期利润分享计划，应计入管理费用，而非利润分配处理。 选项D正确。2×23年每名管理人员未使用带薪年休假2天，总计 20人 × 2天 = 40天。每人每天工资200元。因此，2×23年应确认的未行使带薪年休假费用 = 40天 × 200元/天 = 8000元 = 0.8万元。该费用应计入管理费用。

    6. 题目 下列各项有关设定受益计划的会计处理应计入当期损益的有( )。 - A. 过去服务成本 - B. 计划资产回报，扣除包括在设定受益计划净负债或净资产的利息净额中的金额 - C. 精算利得和损失 - D. 设定受益计划净负债或净资产的利息净额

    答案 AD 解析： 计入当期损益（或资产成本）的设定受益计划金额包括：当期服务成本、过去服务成本、结算利得和损失以及设定受益计划净负债或净资产的利息净额。 计入其他综合收益的设定受益计划金额包括：精算利得和损失、计划资产回报扣除包括在设定受益计划净负债或净资产的利息净额中的金额、资产上限影响的变动扣除包括在设定受益计划净负债或净资产的利息净额中的金额。 因此，选项A和D正确，选项B和C错误。

    三、判断题

    1. 题目 企业应将辞退福利产生的职工薪酬，一次性计入当期管理费用。( )

    答案 √ 解析： 由于被辞退的职工不再为企业带来未来经济利益，因此，对于所有辞退福利，均应当于辞退计划满足负债确认条件的当期一次计入费用，一般计入管理费用，不计入资产成本。

    2. 题目 离职后福利计划可以分为设定提存计划和设定受益计划两种类型。( )

    答案 √ 解析： 离职后福利计划确实分为设定提存计划和设定受益计划两种类型。

    3. 题目 将自有资产或租赁资产无偿提供给职工使用属于非货币性福利。( )

    答案 √ 解析： 将自有资产或租赁资产无偿提供给职工使用，属于企业向职工提供的非货币性福利 [资料外推]。

    4. 题目 重新计量设定受益计划净负债或净资产所产生的变动计入其他综合收益的，在原设定受益 计划终止时，将该其他综合收益结转至未分配利润。( )

    答案 √ 解析： 重新计量设定受益计划净负债或净资产所产生的变动计入其他综合收益，在后续会计期间不允许转回至损益。在原设定受益计划终止时，企业应当在权益范围内将原计入其他综合收益的部分全部结转至未分配利润。
