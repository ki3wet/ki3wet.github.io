# 第三节 合营安排

## 概念及合营安排的认定
指一项由两个或两个以上参与方共同控制的安排。特征是各参与方均受约束且两个或两个以上参与方对相关活动实施一致同意后才能决策。

## 共同经营和合营企业
合营安排分为共同经营（合营方享有相关资产且承担相关负债）和合营企业（合营方仅对净资产享有权利）。
- 判断：主要看是否通过单独主体达成。未通过单独主体达成的，为共同经营。通过单独主体达成的，可能共同经营也可能合营企业。关键看参与方对资产的权利和对负债的义务。

## 共同经营中合营方的会计处理
合营方应确认其利益份额相关的下列项目：单独所持和按份额确认共同持有的资产；单独所承担和按份额确认共同承担的负债；出售享有的产出份额收入；按份额确认共同经营出售产出收入；单独所发生和按份额确认共同经营发生的费用。
- 合营方向共同经营投出或出售不构成业务的资产：仅确认归属于共同经营其他参与方的利得或损失，资产减值损失全额确认。
- 合营方自共同经营购买不构成业务的资产：不应确认因该交易产生的损益中该合营方应享有的部分，仅确认归属于共同经营其他参与方的部分。
