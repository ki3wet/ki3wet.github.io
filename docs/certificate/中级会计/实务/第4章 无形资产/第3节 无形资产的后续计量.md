# 第三节 无形资产的后续计量

## 无形资产使用寿命的确定
- 使用寿命有限的应估计年限或产量；无法预见为企业带来经济利益期限的，视为使用寿命不确定。
- 主要原则（孰短原则）：源自合同性权利或其他法定权利的取短的时间。若合同权利可续约且不付出重大成本，续约期可计入使用寿命。
- 无形资产使用寿命的复核：至少每年年度终了复核使用寿命及摊销方法。有证据表明与以前估计不同，按会计估计变更进行处理。使用寿命不确定的无形资产，有证据表明其使用寿命有限的，也按会计估计变更处理。

## 使用寿命有限的无形资产
- 应摊销金额：成本扣除预计残值后的金额。已计提减值准备的，还应扣除减值准备累计金额。残值一般为零，除非有第三方承诺购买或有活跃市场存在。若残值重新估计后高于账面价值，则无形资产不再摊销，直至残值降至低于账面价值时再恢复摊销。
- 摊销期和摊销方法：自可供使用时起至终止确认时止。摊销方法应反映经济利益的预期消耗方式，如直线法、产量法。无法可靠确定消耗方式的，采用直线法摊销。不能以产生收入为基础摊销，除非合同约定或有确凿证据表明高度相关。
- 会计处理：当月增加当月开始摊销，当月减少当月停止摊销。摊销根据用途计入管理费用、制造费用/生产成本等。

## 使用寿命不确定的无形资产
在持有期间内不需要进行摊销，但应当至少在每个会计期末进行减值测试。
