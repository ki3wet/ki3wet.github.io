# 第三节 财务报告目标、会计要素和会计信息质量要求

## 财务报告目标
包括决策有用观（提供有助于经济决策的信息）和受托责任观（反映管理层受托责任履行情况）。

## 企业会计要素及其确认条件
- 资产：过去的交易事项形成的、企业拥有或控制的、预期会带来经济利益的资源。确认条件是经济利益很可能流入企业且成本或价值能可靠计量。
- 负债：过去的交易事项形成的、预期会导致经济利益流出企业的现时义务。确认条件是经济利益很可能流出企业且金额能可靠计量。现时义务可以是法定义务或推定义务。
- 所有者权益：企业资产扣除负债后的剩余权益。主要来源是所有者投入的资本、直接计入所有者权益的利得和损失（通过"其他综合收益"核算）和留存收益等。其确认和金额确定主要依赖于资产和负债的确认和计量。利得和损失是由企业非日常活动形成的，会导致所有者权益增减的经济利益流入流出。
- 收入：企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益总流入。销售商品和提供劳务收入在履行履约义务时确认；让渡资金使用权收入在资产负债表日按时间和实际利率计算确定。
- 费用：企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益总流出。确认条件是经济利益很可能流出、导致资产减少或负债增加且流出额能可靠计量。
- 利润：企业在一定会计期间的经营成果。包括收入减去费用后的净额、直接计入当期利润的利得和损失等。

## 会计信息质量要求

- 可靠性：强调真实，要求以实际发生的交易为依据，保证信息完整、客观中立。
- 相关性：强调有用，具有预测价值和反馈价值，尽可能满足决策需要。
- 可理解性：要求会计信息清晰明了，便于使用者理解和使用。
- 可比性：包括纵向可比（同一企业不同时期采用一致会计政策）和横向可比（不同企业同一时期会计政策相互可比）。
- 实质重于形式：要求按交易经济实质进行确认、计量和报告，而非仅以法律形式为依据。
- 重要性：要求反映与企业财务状况、经营成果和现金流量有关的所有重要交易或事项，并从金额和性质两方面判断。
- 谨慎性：要求对交易保持应有的谨慎，不应高估资产或收益，不应低估负债或费用（不允许设置秘密准备）。
- 及时性：要求及时收集、处理和传递会计信息，并在及时性和可靠性之间权衡。

## 会计要素计量属性（补充）
包括历史成本、重置成本、可变现净值、现值和公允价值。
