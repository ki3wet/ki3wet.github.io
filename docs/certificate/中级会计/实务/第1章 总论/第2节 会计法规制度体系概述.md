# 第二节 会计法规制度体系概述

## 会计法规制度体系的构成
指国家权力机关和行政机关制定的，用以调整会计关系的各种法律、法规、规章和规范性文件的总称。我国已形成以《会计法》为主体，由会计法律、会计行政法规、会计部门规章和规范性文件构成的体系。

## 国家统一的会计制度体系概述
指国务院财政部门根据《会计法》制定的关于会计核算、会计监督、会计机构和会计人员以及会计工作管理的制度。主要包括企业会计准则制度（适用于上市公司、金融机构及大中型国有企业等；小企业会计准则适用于小型企业，但公开交易、金融性质、集团内母子公司除外；企业会计制度适用于其他企业）、政府及非营利组织会计准则制度（如政府会计准则适用于各级政府、部门、单位；非营利组织会计制度适用于民间非营利组织和各级工会）及其他会计制度。
