# 第一节 固定资产的确认和初始计量

## 固定资产的定义和确认条件
指为生产商品、提供劳务、出租或经营管理而持有，且使用寿命超过一个会计年度的有形资产。确认条件是与该固定资产相关的经济利益很可能流入企业，且成本能可靠计量。

## 固定资产确认条件的具体应用
为安全或环保要求购入的设备，虽不能直接带来经济利益，但有助于从其他相关资产使用中获得经济利益的，应确认为固定资产。固定资产各组成部分具有不同使用寿命或以不同方式提供经济利益的，应确认为单项固定资产。数量多、单价低的工具、用具、备品备件等，通常确认为存货。

## 固定资产的初始计量
固定资产应按成本初始计量。

### 外购固定资产
成本包括购买价款、相关税费（如关税、契税、车辆购置税等）和使固定资产达到预定可使用状态前所发生的可归属于该项资产的运输费、装卸费、安装费和专业人员服务费等。需要安装的，先通过"在建工程"科目核算。

### 自行建造固定资产
- 自营方式：为建造固定资产准备的物资按实际成本（工程物资）核算。建造期间的土地使用权摊销应资本化计入固定资产建造成本。盘亏、报废、毁损的工程物资，若工程未完工计入工程成本，已完工计入营业外支出；非常原因造成的直接计入营业外支出。达到预定可使用状态但未办理竣工决算的，按暂估价值转入固定资产并计提折旧，竣工决算后再调整暂估价值但不调整原已计提折旧。
- 出包方式：入账价值包括建筑工程支出、安装工程支出、安装设备支出和分摊的待摊支出。
- 试运行销售：固定资产达到预定可使用状态前或研发过程中产出的产品或副产品对外销售，应按收入、存货等相关准则规定，将收入和成本分别进行会计处理，计入当期损益。测试固定资产正常运转发生的支出计入固定资产成本。

### 其他方式取得的固定资产
接受投资的固定资产，按合同约定价值加相关税费作为入账价值，若不公允则按公允价值入账，差额计入资本公积。

### 存在弃置费用的固定资产
特定行业应将弃置费用的现值计入相关固定资产成本，同时确认预计负债。使用寿命内，预计负债的利息费用计入财务费用。弃置义务变动应调整固定资产成本，超出账面价值的部分确认为当期损益。一般企业的报废清理费用属于处置费用。
