# 第二节 固定资产的后续计量

## 固定资产折旧
在固定资产使用寿命内，按确定方法对应计折旧额进行系统分摊。应计折旧额是原价扣除预计净残值和已计提减值准备后的金额。

### 固定资产折旧范围
除已提足折旧仍继续使用的和单独计价入账的土地外，所有固定资产均应计提折旧。未使用、不需用的固定资产照提折旧。更新改造过程中停止使用的转入在建工程，不再计提折旧。

### 固定资产折旧方法
应根据经济利益预期消耗方式合理选择，可选年限平均法、工作量法、双倍余额递减法和年数总和法等。双倍余额递减法和年数总和法是加速折旧法。折旧方法一经确定不得随意变更。不能以产生收入为基础计提折旧。

### 固定资产折旧的会计处理
按月计提折旧。当月增加的固定资产当月不计提，下月起计提；当月减少的当月仍计提，下月起不计提。折旧根据用途计入相关资产成本或当期损益。

### 固定资产使用寿命、预计净残值和折旧方法的复核
至少每年年度终了复核。有差异的，按会计估计变更进行处理（未来适用法，不追溯调整）。

## 固定资产后续支出
指固定资产使用过程中发生的更新改造支出、修理费用等。资本化后续支出（符合固定资产确认条件）计入固定资产成本，同时将被替换部分的账面价值扣除。费用化后续支出（不符合资本化条件）计入当期损益。
