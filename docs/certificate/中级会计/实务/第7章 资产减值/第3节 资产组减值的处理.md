# 第三节 资产组减值的处理

## 资产组的认定
企业可认定的最小资产组合，其产生的现金流入应基本上独立于其他资产或资产组产生的现金流入。认定应考虑管理层管理生产经营活动的方式和对资产持续使用或处置的决策方式。资产组一经确定，在各会计期间应保持一致，不得随意变更。

## 资产组可收回金额和账面价值的确定
可收回金额按资产组公允价值减去处置费用后的净额与预计未来现金流量现值较高者确定。账面价值应包括可直接归属于资产组与可合理一致地分摊至资产组的资产账面价值，不包括已确认负债的账面价值。

## 资产组减值测试
如果资产组可收回金额低于账面价值，应确认相应减值损失。减值损失分摊顺序：首先抵减商誉账面价值；然后按除商誉之外的其他各项资产账面价值比重，按比例抵减。抵减后的各资产账面价值不得低于公允价值减处置费用后的净额、预计未来现金流量现值和零三者中的最高者。

## 总部资产的减值测试
总部资产通常难以单独进行减值测试，需结合其他相关资产组或资产组组合进行。若总部资产能分摊至资产组，将其分摊至资产组账面价值进行比较。若不能分摊，则先不考虑总部资产测试资产组是否减值，减值后将减值损失分摊给总部资产和资产组。
