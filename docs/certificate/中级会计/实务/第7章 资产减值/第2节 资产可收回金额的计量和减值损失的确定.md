# 第二节 资产可收回金额的计量和减值损失的确定

## 资产可收回金额计量的基本要求
根据资产的公允价值减去处置费用后的净额与资产预计未来现金流量的现值两者之间较高者确定。只需估计其中一项超过账面价值即可。若无确凿证据表明预计未来现金流量现值显著高于公允价值减去处置费用后的净额，可将后者视为可收回金额。

## 资产预计未来现金流量现值的预计
- 考虑因素：资产预计未来现金流量、使用寿命、折现率。
- 预计内容：资产持续使用产生的现金流入、为实现现金流入必需的现金流出、资产使用寿命结束时处置资产的净现金流量。在建工程或开发中的无形资产，应包括预期为达到预定可使用状态而发生的全部现金流出。
- 不包括事项：将来可能发生的尚未承诺的重组事项、与资产改良有关的预计未来现金流量、筹资活动和所得税收付有关的现金流量。
- 方法：传统法（最可能现金流量，单一折现率）和期望现金流量法（每期现金流量期望值加权平均）。
- 折现率：应反映当前市场货币时间价值和资产特定风险的税前利率。

## 资产减值损失的确定及其账务处理
如果资产可收回金额低于账面价值，应将账面价值减记至可收回金额，差额确认为资产减值损失，计入当期损益，同时计提相应资产减值准备。资产减值损失一经确认，在以后会计期间不得转回。符合终止确认条件的资产减少时，应转销相关资产减值准备。
