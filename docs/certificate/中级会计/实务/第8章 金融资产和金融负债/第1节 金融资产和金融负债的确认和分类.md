# 第一节 金融资产和金融负债的确认和分类

## 金融工具
形成一方的金融资产并形成其他方的金融负债或权益工具的合同。

## 金融资产的分类
根据企业管理金融资产的业务模式和金融资产的合同现金流量特征，将金融资产划分为：
- 以摊余成本计量的金融资产【摊】：业务模式为收取合同现金流量，且合同现金流量特征为本金加利息。
- 以公允价值计量且其变动计入其他综合收益的金融资产【综】：
  - 【综(债)】：业务模式为既收取合同现金流量又出售金融资产，且合同现金流量特征为本金加利息。
  - 【综(股)】：非交易性的权益工具投资，在初始确认时可指定为此类，一经指定不得撤销，不需计提减值准备。
- 以公允价值计量且其变动计入当期损益的金融资产【损(债)、损(股)】：上述两类之外的金融资产。若能消除或显著减少会计错配，初始确认时可指定为此类，一经指定不得撤销。

## "交易性"的判断
目的主要是近期出售或回购；属于集中管理的可辨认金融工具组合且有客观证据表明近期有短期获利目的；属于衍生工具。

## 金融负债的分类
金融负债主要包括应付账款、长期借款、其他应付款、应付票据、应付债券、衍生金融负债等。分为以公允价值计量且其变动计入当期损益的金融负债（包括交易性、指定为FVPL）和以摊余成本计量的金融负债等。企业对金融负债的分类一经确定，不得随意变更。
