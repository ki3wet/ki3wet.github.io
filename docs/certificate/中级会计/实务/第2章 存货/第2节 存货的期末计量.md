# 第二节 存货的期末计量

## 存货期末计量原则
资产负债表日，存货应当按照成本与可变现净值孰低计量。可变现净值是指日常活动中，存货的估计售价减去至完工时将要发生的成本、估计的销售费用以及相关税费后的金额。存货成本高于可变现净值时，应计提存货跌价准备，计入当期损益（资产减值损失）。

## 存货期末计量方法
- 存货减值迹象的判断：包括市场价格持续下跌、产品成本大于销售价格、原材料不适应新产品需要、市场需求变化导致价格下跌以及其他证明存货已减值的情形。已霉烂变质、过期无转让价值、不再需要且无使用价值和转让价值的存货，可变现净值为零，应全额计提。
- 可变现净值的确定：考虑确凿证据、持有目的和资产负债表日后事项等影响。直接出售产品的可变现净值是其估计售价减去相关税费；需要加工的材料的可变现净值是产成品的估计售价减去产品相关税费和加工成本。
- 存货跌价准备的计提与转回：应按单个存货项目计提，或按存货类别/性质相似的存货计提，或在某些特定类别存货数量繁多、单价较低时按存货类别汇总计提。减值损失一经确认可以转回，但转回金额以原计提的存货跌价准备金额为限。
- 结转存货跌价准备：已销售的存货，在结转销售成本时，应同时结转对其已计提的存货跌价准备。
