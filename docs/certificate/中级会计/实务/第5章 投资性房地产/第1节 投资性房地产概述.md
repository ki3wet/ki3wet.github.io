# 第一节 投资性房地产概述

## 投资性房地产的定义与特征
为赚取租金或资本增值，或两者兼有而持有的房地产。特征是经营性活动，且用途、状态、目的不同于生产经营场所和用于销售的房地产。

## 投资性房地产的范围
包括已出租的土地使用权、持有并准备增值后转让的土地使用权和已出租的建筑物。企业计划用于出租但尚未出租的土地使用权不属于；租入再转租的建筑物不属于。对持有以备出租的空置建筑物或在建建筑物，如董事会书面决议明确用于出租且意图短期内不变的，即使未签租赁协议，也应视为投资性房地产。企业将建筑物出租，提供的辅助服务不重大时，确认为投资性房地产。

## 不属于投资性房地产的项目
自用房地产（如自用的办公大楼属固定资产，自用土地使用权属无形资产）；作为存货的房地产（如房地产开发企业销售或正在开发的商品房和土地使用权）。若房地产部分自用、部分出租且能单独计量和出售的，出租部分确认为投资性房地产；不能单独计量和出售的，整体确认为固定资产或无形资产。
