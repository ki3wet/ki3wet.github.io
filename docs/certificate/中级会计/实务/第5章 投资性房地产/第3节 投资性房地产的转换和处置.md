# 第三节 投资性房地产的转换和处置

## 投资性房地产的转换

### 形式及转换日
- 投转非：投资性房地产开始自用（转换为固定资产或无形资产），转换日为房地产达到自用状态并开始用于生产、提供劳务或经营管理之日。投资性房地产转为存货（房地产开发企业），转换日为租赁期届满、董事会书面决议明确重新开发用于对外销售之日。
- 非转投：作为存货的房地产改为出租，转换日为租赁期开始日。自用建筑物停止自用改为出租，或自用土地使用权停止自用改为赚取租金或资本增值，转换日为确定用于赚取租金或资本增值之日。

### 会计处理
- 成本模式：转换前后资产均计提折旧/摊销/减值的，进行对应结转（原值转原值、折旧转折旧、摊销转摊销、减值准备转减值准备）。不具备对应转换条件的，按原资产账面价值入账。成本模式下的转换不产生转换差额。
- 公允价值模式：
  - 投转非：转换为自用房地产或存货时，按公允价值入账，公允价值与账面价值的差额计入公允价值变动损益。
  - 非转投：自用房地产转换为投资性房地产时，按公允价值入账，公允价值大于账面价值的差额计入其他综合收益，公允价值小于账面价值的差额计入公允价值变动损益。存货转换为投资性房地产时，按公允价值入账，公允价值大于账面价值的差额计入其他综合收益，公允价值小于账面价值的差额计入公允价值变动损益。处置时，将其他综合收益和公允价值变动损益转入当期损益（其他业务成本）。

## 投资性房地产的处置
企业出售、转让、报废投资性房地产或发生毁损，应将处置收入扣除其账面价值和相关税费后的金额计入当期损益（实际收到的处置收入计入其他业务收入，账面价值计入其他业务成本）。公允价值模式下，处置时将之前确认的其他综合收益和公允价值变动损益转入其他业务成本。
