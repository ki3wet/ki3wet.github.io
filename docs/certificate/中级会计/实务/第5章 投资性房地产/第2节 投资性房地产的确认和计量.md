# 第二节 投资性房地产的确认和计量

## 投资性房地产的确认
符合定义，且相关经济利益很可能流入企业，成本能可靠计量。

## 投资性房地产的计量
- 计量原则：
  - 外购：购入同时开始出租或用于资本增值时确认。若自用一段时间后改为出租，应先确认为固定资产或无形资产，再转换为投资性房地产。按实际成本初始计量。
  - 自行建造：建造完成（达到预定可使用状态）同时开始出租或用于资本增值时确认。初始成本由达到预定可使用状态前发生的必要支出构成。
  - 后续计量：有成本模式和公允价值模式两种。同一企业只能采用一种模式对所有投资性房地产进行后续计量。
- 成本模式：允许提折旧、摊销、减值准备，但已计提的减值准备不允许转回。
- 公允价值模式：不允许提折旧、摊销、减值准备。只有存在确凿证据表明公允价值能持续可靠取得，且所在地有活跃交易市场、能取得同类或类似房地产市场价格等信息，才能采用。
- 账务处理：初始确认、收租金、折旧（成本模式）、公允价值变动（公允价值模式）、减值（成本模式）、后续支出等。

## 投资性房地产后续计量模式的变更
一经确定，不得随意变更。成本模式变更为公允价值模式时，作为会计政策变更处理，按计量模式变更时公允价值与账面价值的差额，调整期初留存收益（盈余公积、利润分配—未分配利润）。已采用公允价值模式计量的，不得变更为成本模式。
