# SQL 基础知识总结

## 数据类型与数据库简介

### 数据分类
- **结构化数据**：以二维表形式存储的数据，具有行和列。
- **非结构化数据**：如视频、音频等。

### 数据库种类
常见的数据库包括：
- ORACLE
- OCEANBASE
- 达梦
- MySQL
- DB2
- 高斯
- 人大金仓

这些数据库用于存储公司业务系统的数据。

## SQL 简介

SQL 全称是 **Structured Query Language**（结构化查询语言），通过 SQL 可以访问和操作数据库中的数据。

### 基本查询语法
```sql
SELECT * FROM emp;
```

#### 关键字说明
- `SELECT`：选择要查询的字段。
- `*`：表示所有字段。
- `FROM`：指定数据来源的表。
- `emp`：表名。
- `;`：结束语句。

#### 示例
1. 查询所有员工信息：
   ```sql
   SELECT * FROM EMP;
   ```

2. 查询每个员工的姓名和部门编号：
   ```sql
   SELECT ENAME, DEPTNO FROM EMP;
   ```

3. 给字段起别名：
   ```sql
   SELECT ENAME 员工名字, DEPTNO AS 部门编号 FROM EMP;
   ```

4. 给表起别名：
   ```sql
   SELECT T.EMPNO, T.ENAME, T.JOB, T.MGR, T.HIREDATE, T.SAL, T.COMM, T.DEPTNO FROM EMP T;
   ```

5. 查询特定字段：
   ```sql
   SELECT EMPNO, ENAME, JOB, MGR, HIREDATE, SAL, COMM, DEPTNO FROM EMP;
   ```

---

## 注释

- **单行注释**：使用 `--`
  ```sql
  -- 这是一个单行注释
  SELECT * FROM EMP;
  ```

- **多行注释**：使用 `/* ... */`
  ```sql
  /*
  这是一个
  多行注释
  */
  SELECT * FROM EMP;
  ```

## 条件查询 (WHERE)

`WHERE` 子句用于对数据进行过滤。

### 比较运算符
| 符号 | 含义         |
|------|--------------|
| `>`  | 大于         |
| `>=` | 大于等于     |
| `<`  | 小于          |
| `<=` | 小于等于      |
| `=`  | 等于          |
| `<>` 或 `!=` | 不等于 |

#### 示例
1. 查询 10 号部门的员工：
   ```sql
   SELECT * FROM EMP WHERE DEPTNO = 10;
   ```

2. 查询工资大于 2000 的员工：
   ```sql
   SELECT * FROM EMP WHERE SAL > 2000;
   ```

3. 查询不是 30 号部门的员工：
   ```sql
   SELECT * FROM EMP WHERE DEPTNO != 30;
   ```

4. 查询 SMITH 的信息：
   ```sql
   SELECT * FROM EMP WHERE ENAME = 'SMITH';
   ```

> 注意：字符串类型的条件需要用单引号 `' '` 包裹，并且大小写敏感（在 Oracle 中）。

## 字段类型与转换函数

### 常见字段类型
- `VARCHAR2(X)`：可变长度字符串。
- `CHAR(X)`：定长字符串。
- `NUMBER(X,Y)`：数字类型，X 表示总长度，Y 表示小数位数。
- `DATE`：日期类型。

### 转换函数
1. **TO_DATE()**：将字符串转换为日期。
   ```sql
   TO_DATE('20250708', 'YYYYMMDD')
   ```

2. **TO_CHAR()**：将日期或数字转换为字符串。
   ```sql
   TO_CHAR(SYSDATE, 'YYYY-MM-DD')
   ```

3. **TO_NUMBER()**：将纯数字字符串转换为数字。
   ```sql
   TO_NUMBER('12345')
   ```

4. **CAST()**：通用类型转换。
   ```sql
   CAST(EMPNO AS VARCHAR2(10))
   ```

## 多条件查询 (AND / OR)

### 逻辑运算符
- `AND`：并且（交集）
- `OR`：或者（并集）

#### 示例
1. 查询 10 号部门工资大于 2000 的员工：
   ```sql
   SELECT * FROM EMP WHERE DEPTNO = 10 AND SAL > 2000;
   ```

2. 查询 10 号部门或工资大于 2000 的员工：
   ```sql
   SELECT * FROM EMP WHERE DEPTNO = 10 OR SAL > 2000;
   ```

3. 查询 20 和 30 号部门的员工：
   ```sql
   SELECT ENAME FROM EMP WHERE DEPTNO = 20 OR DEPTNO = 30;
   ```

4. 查询 20 和 30 号部门中工资大于 2000 的员工：
   ```sql
   SELECT * FROM EMP 
   WHERE (DEPTNO = 20 OR DEPTNO = 30) AND SAL > 2000;
   ```

## 练习

### 查询 1981 年入职的员工

#### 方法一：使用 `TO_CHAR()`
```sql
SELECT ENAME, HIREDATE
FROM EMP 
WHERE (DEPTNO = 20 OR DEPTNO = 30) 
  AND TO_CHAR(HIREDATE, 'YYYY') = '1981';
```

#### 方法二：使用 `TO_DATE()`
```sql
SELECT ENAME, HIREDATE
FROM EMP 
WHERE (DEPTNO = 20 OR DEPTNO = 30) 
  AND HIREDATE > TO_DATE('19801231', 'YYYYMMDD')
  AND HIREDATE < TO_DATE('19820101', 'YYYYMMDD');
```

### 练习 1：查询奖金高于 1000 且工资高于 1500 的员工信息

#### 解析
- 查询字段：所有字段 `SELECT *`
- 条件：
  - 奖金 `COMM > 1000`
  - 工资 `SAL > 1500`
  - 两个条件同时满足，使用 `AND`

#### SQL 语句
```sql
SELECT * FROM EMP
WHERE COMM > 1000 AND SAL > 1500;
```

### 练习 2：查询所有销售员的名字

#### 解析
- 查询字段：员工名字 `ENAME`
- 条件：职位是 `'SALESMAN'`
- 注意：字符串值必须用单引号包裹，否则会报错

#### SQL 语句
```sql
SELECT ENAME FROM EMP
WHERE JOB = 'SALESMAN';
```

---

### 练习 3：查找 10 号部门中所有经理和 20 号部门中所有客服的详细信息

#### 解析
- 查询字段：所有字段 `SELECT *`
- 条件：
  - 10 号部门且职位是经理：`DEPTNO = 10 AND JOB = 'MANAGER'`
  - 20 号部门且职位是客服：`DEPTNO = 20 AND JOB = 'CLERK'`
  - 两个条件取并集，使用 `OR`
- 使用括号保证逻辑清晰

#### SQL 语句
```sql
SELECT * FROM EMP
WHERE (DEPTNO = 10 AND JOB = 'MANAGER')
   OR (DEPTNO = 20 AND JOB = 'CLERK');
```

---

### 练习 4：查找 10 号部门中所有经理、20 号部门中所有客服，以及既不是经理又不是客服但工资 > 2000 的员工名字、工作、工资，并起别名

#### 解析
- 查询字段：`ENAME 名字`, `JOB 工作`, `SAL 工资`
- 条件：
  - 10 号部门且职位是经理：`DEPTNO = 10 AND JOB = 'MANAGER'`
  - 20 号部门且职位是客服：`DEPTNO = 20 AND JOB = 'CLERK'`
  - 既不是经理也不是客服且工资 > 2000：`JOB NOT IN ('MANAGER', 'CLERK') AND SAL > 2000`
- 三个条件取并集，使用 `OR`

#### SQL 语句
```sql
SELECT ENAME 名字, JOB 工作, SAL 工资
FROM EMP
WHERE (DEPTNO = 10 AND JOB = 'MANAGER')
   OR (DEPTNO = 20 AND JOB = 'CLERK')
   OR (JOB NOT IN ('MANAGER', 'CLERK') AND SAL > 2000);
```

---

### 练习 5：查找 20 号部门 1981 年入职的所有员工信息

#### 解析
- 查询字段：所有字段 `SELECT *`
- 条件：
  - 部门编号为 20：`DEPTNO = 20`
  - 入职时间在 1981 年：
    - 方法 1：使用 `TO_CHAR(HIREDATE, 'YYYY') = '1981'`
    - 方法 2：使用 `BETWEEN TO_DATE('19810101', 'YYYYMMDD') AND TO_DATE('19811231', 'YYYYMMDD')`

#### SQL 语句（方法 1）
```sql
SELECT * FROM EMP
WHERE DEPTNO = 20
  AND TO_CHAR(HIREDATE, 'YYYY') = '1981';
```

#### SQL 语句（方法 2）
```sql
SELECT * FROM EMP
WHERE DEPTNO = 20
  AND HIREDATE BETWEEN TO_DATE('19810101', 'YYYYMMDD') AND TO_DATE('19811231', 'YYYYMMDD');
```

---

### 练习 6：查询不在 20 和 30 号部门的员工信息

#### 解析
- 查询字段：所有字段 `SELECT *`
- 条件：
  - 部门编号不在 20 和 30 中：`DEPTNO NOT IN (20, 30)`

#### SQL 语句
```sql
SELECT * FROM EMP

```

### 练习 7：模糊查询

#### 示例 1：查询员工名字中第三个字母为 A 的员工信息
```sql
SELECT * FROM EMP
WHERE ENAME LIKE '__A%';
```

#### 示例 2：查询名字长度为 4 的员工名字
```sql
SELECT ENAME FROM EMP
WHERE ENAME LIKE '____';
```

#### 示例 3：查询名字以 S 开头的员工名字
```sql
SELECT ENAME FROM EMP
WHERE ENAME LIKE 'S%';
```

---

### 练习 8：处理 NULL 值

#### 示例 1：查询奖金为空的员工信息
```sql
SELECT * FROM EMP
WHERE COMM IS NULL;
```

#### 示例 2：计算员工总薪资（考虑 NULL 值）
```sql
SELECT ENAME, SAL, COMM, SAL + NVL(COMM, 0) 总薪资
FROM EMP;
```

---

### 练习 9：排序查询

#### 示例 1：按工资降序排列员工信息
```sql
SELECT * FROM EMP
ORDER BY SAL DESC;
```

#### 示例 2：按工资降序、部门编号升序排列员工信息
```sql
SELECT * FROM EMP
ORDER BY SAL DESC, DEPTNO ASC;
```

---

### 练习 10：计算年薪并排序

#### 示例：查找年薪低于 20000 的员工名字、工资、年薪，并按年薪降序排列
```sql
SELECT ENAME, SAL, 12 * (SAL + NVL(COMM, 0)) 年薪
FROM EMP
WHERE 12 * (SAL + NVL(COMM, 0)) < 20000
ORDER BY 年薪 DESC;
```

---

### 练习 11：多条件组合查询

#### 示例：查找第二季度入职，且职位是经理或分析师的员工名字、职位、入职季度
```sql
SELECT ENAME, JOB, TO_CHAR(HIREDATE, 'Q') 季度
FROM EMP
WHERE TO_CHAR(HIREDATE, 'Q') = '2'
  AND JOB IN ('MANAGER', 'ANALYST');
```

---

### 练习 12：复杂多条件查询

#### 示例：查找名字第二个字母为 M，既不是 10 号也不是 20 号部门，且薪资不在 2000-3000 之间的员工信息
```sql
SELECT * FROM EMP
WHERE SUBSTR(ENAME, 2, 1) = 'M'
  AND DEPTNO NOT IN (10, 20)
  AND SAL NOT BETWEEN 2000 AND 3000;
```

---

### 练习 13：时间范围 + 模糊匹配

#### 示例：查询 1981 年到 1982 年入职且名字含 S 的员工名字、部门编号、职位、入职年份、年薪
```sql
SELECT ENAME, DEPTNO, JOB, TO_CHAR(HIREDATE, 'YYYY') 年份, 12 * (SAL + NVL(COMM, 0)) 年薪
FROM EMP
WHERE HIREDATE BETWEEN TO_DATE('19810101', 'YYYYMMDD') AND TO_DATE('19821231', 'YYYYMMDD')
  AND ENAME LIKE '%S%';
```

---

### 练习 14：排除特定职位 + 奖金非空

#### 示例：查询不是经理和分析师，且奖金不为空的员工信息
```sql
SELECT * FROM EMP
WHERE JOB NOT IN ('MANAGER', 'ANALYST')
  AND COMM IS NOT NULL;
```

### 总结

- 使用 `AND` 和 `OR` 搭配括号，可以构建复杂的多条件查询逻辑。
- 对于 `NULL` 值，不能使用 `= NULL` 或 `!= NULL`，必须使用 `IS NULL` 或 `IS NOT NULL`。
- `LIKE` 可以结合通配符 `%` 和 `_` 实现模糊匹配。
- 使用 `TO_CHAR`、`TO_DATE` 等函数可以处理日期和字符串之间的转换。
- 排序使用 `ORDER BY`，支持多字段排序。
- 年薪等计算字段可以使用 `NVL` 处理空值，确保结果正确。

这些练习涵盖了 SQL 查询中常见的操作，包括条件过滤、排序、空值处理、模糊查询、日期处理、多条件组合等。熟练掌握这些技巧有助于编写高效、准确的 SQL 查询语句。

## 总结

- SQL 是一种强大的结构化查询语言，用于操作数据库。
- 使用 `SELECT` 查询数据，结合 `WHERE` 进行条件过滤。
- 掌握基本的字段类型和转换函数（如 `TO_DATE`, `TO_CHAR`, `TO_NUMBER`, `CAST`）。
- 熟悉逻辑运算符 `AND` 和 `OR` 的优先级，必要时使用括号提升优先级。
