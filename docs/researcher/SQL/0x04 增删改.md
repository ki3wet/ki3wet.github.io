# 表的增删改

## 一、建表（CREATE TABLE）

### 语法：
```sql
CREATE TABLE 表名 (
    字段名1 类型1,
    字段名2 类型2,
    ...
);
```

### 常用字段类型：

| 类型         | 说明 |
|--------------|------|
| `VARCHAR2(X)` | 可变长度字符串 |
| `CHAR(X)`     | 定长字符串 |
| `NUMBER(X,Y)` | 数值类型，X表示总位数，Y表示小数位数 |
| `DATE`        | 日期类型，需使用 `TO_DATE()` 转换 |
| `TIMESTAMP`   | 带毫秒的时间戳 |

### 示例：创建学生信息表 `STU_0711`

```sql
CREATE TABLE STU_0711 (
    ID NUMBER(8),
    NAME VARCHAR2(10),
    GENDER VARCHAR2(10),
    START_TIME DATE,
    PHONE NUMBER(11)
);

SELECT * FROM STU_0711; -- 查看空表结构
```

## 二、插入数据（INSERT INTO）

### 语法：
```sql
INSERT INTO 表名 (字段1, 字段2, ...)
VALUES (值1, 值2, ...);
```

### 插入示例：

#### 全字段插入
```sql
INSERT INTO STU_0711 (ID, NAME, GENDER, START_TIME, PHONE)
VALUES (20250001, '小小', '女', TO_DATE('20250101', 'YYYYMMDD'), 18719087654);
```

> ⚠️ 注意：日期类型需要使用 `TO_DATE()` 函数转换。

#### 省略字段名插入（默认全字段）
```sql
INSERT INTO STU_0711
VALUES (20250002, '刚子', '男', TO_DATE('20241231', 'YYYYMMDD'), 13619080654);
```

#### 部分字段插入
```sql
INSERT INTO STU_0711 (ID, GENDER, START_TIME, PHONE)
VALUES (20250004, '男', TO_DATE('20241130', 'YYYYMMDD'), 13461908765);
```

> ✅ DML 操作（如 INSERT）需要手动提交事务：
```sql
COMMIT;
```

## 三、修改数据（UPDATE）

### 语法：
```sql
UPDATE 表名 SET 字段 = 值 WHERE 条件;
```

> ⚠️ 不加 `WHERE` 将更新整张表！

### 示例：
```sql
UPDATE STU_0711 
SET ID = 20250010, NAME = '笨笨' 
WHERE ID = 20250004 AND GENDER = '男';
```

> ✅ 同样属于 DML，操作后需提交事务：
```sql
COMMIT;
```

---

## 四、删除数据（DELETE / TRUNCATE / DROP）

### 1. DELETE 删除数据（DML）

- 支持带条件删除
- 需要 `COMMIT` 或 `ROLLBACK`

```sql
-- 删除特定记录
DELETE FROM STU_0711
WHERE ID = 20250004 AND NAME = '男';

COMMIT;
```

> ❗不加 `WHERE` 表示清空整张表。

---

### 2. TRUNCATE 清空数据（DDL）

- 快速清空整张表
- 不可回滚
- 重置水位线（释放空间）

```sql
TRUNCATE TABLE STU_0711;
```

---

### 3. DROP 删除表（DDL）

- 删除整个表（包括结构和数据）
- 不可回滚

```sql
DROP TABLE STU_0711;
```

---

### 面试常问：DELETE vs TRUNCATE vs DROP

| 对比项       | DELETE                          | TRUNCATE                        | DROP                           |
|-------------|----------------------------------|----------------------------------|--------------------------------|
| 类型        | DML                              | DDL                              | DDL                            |
| 是否可回滚  | ✅ 是                             | ❌ 否                             | ❌ 否                           |
| 是否能加 WHERE | ✅ 是                             | ❌ 否（只能删除全部）             | ❌ 否                           |
| 是否释放空间 | ❌ 否                             | ✅ 是                             | ✅ 是                           |
| 效率        | 较慢（逐行删除）                 | 快                                | 最快                           |
| 是否影响结构 | ❌ 否                             | ❌ 否                             | ✅ 是                           |

## 五、练习题

### 1. 创建 EMP_0711 表（两种方式）

#### 方法一：显式定义字段
```sql
CREATE TABLE EMP_0711 (
    "EMPNO" NUMBER(4,0), 
    "ENAME" VARCHAR2(10), 
    "JOB" VARCHAR2(9), 
    "MGR" NUMBER(4,0), 
    "HIREDATE" DATE, 
    "SAL" NUMBER(7,2), 
    "COMM" NUMBER(7,2), 
    "DEPTNO" NUMBER(2,0)
);
```

#### 方法二：基于现有表结构复制（不复制数据）
```sql
CREATE TABLE EMP_0711 AS SELECT * FROM EMP WHERE 1=2;
```

---

### 2. 插入 EMP 表中部门编号为 20 的数据到 EMP_0711

#### 方法一：全字段插入
```sql
INSERT INTO EMP_0711
SELECT * FROM EMP WHERE DEPTNO = 20;
COMMIT;
```

#### 方法二：部分字段插入
```sql
INSERT INTO EMP_0711 (ENAME, EMPNO, DEPTNO)
SELECT ENAME, EMPNO, DEPTNO FROM EMP WHERE DEPTNO = 20;
COMMIT;
```

---

### 3. 给薪资低于 2000 的员工涨薪 200

```sql
UPDATE EMP_0711
SET SAL = SAL + 200
WHERE SAL < 2000;
COMMIT;
```

---

### 4. 删除 1982 年入职的员工信息

```sql
DELETE FROM EMP_0711
WHERE TO_CHAR(HIREDATE, 'YYYY') = '1982';
COMMIT;
```

---

### 5. 清空 EMP_0711 表

```sql
TRUNCATE TABLE EMP_0711;
```

---

### 6. 删除 EMP_0711 表

```sql
DROP TABLE EMP_0711;
```

## 七、字符集与字节长度（补充知识）

| 数据库 | 中文字符占用字节数 |
|--------|-------------------|
| Oracle | 2 字节（GBK 编码）|
| GaussDB | 3 字节（UTF-8）   |

例如：

- `VARCHAR2(3)` 可容纳一个中文名（2字节），但不能存“高斯”（GaussDB 中是 6 字节）

## 总结

| 操作 | 关键字 | 是否需要 COMMIT | 是否影响结构 | 是否释放空间 |
|------|--------|------------------|---------------|---------------|
| 插入数据 | INSERT | ✅ 是           | ❌ 否          | ❌ 否          |
| 修改数据 | UPDATE | ✅ 是           | ❌ 否          | ❌ 否          |
| 删除数据 | DELETE | ✅ 是           | ❌ 否          | ❌ 否          |
| 清空数据 | TRUNCATE | ❌ 否         | ❌ 否          | ✅ 是          |
| 删除表 | DROP | ❌ 否              | ✅ 是          | ✅ 是          |
