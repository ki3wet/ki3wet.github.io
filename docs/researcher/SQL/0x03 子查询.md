# 子查询

## 概念

将一个查询语句嵌套在另一个查询语句中，用于**筛选数据**或**作为查询条件**。

子查询一般使用括号 `()` 包裹，以避免语法错误。

---

## 子查询的使用场景

### 1. 放在 `WHERE` 后面作为条件

#### 示例 1：查询工资比 `SCOTT` 高的员工信息

```sql
-- 步骤 1：查出 SCOTT 的工资
SELECT SAL FROM EMP WHERE ENAME = 'SCOTT'; -- 假设结果为 3000

-- 步骤 2：查出工资高于 3000 的员工
SELECT * FROM EMP WHERE SAL > 3000;

-- 合并写法（使用子查询）
SELECT * FROM EMP 
WHERE SAL > (SELECT SAL FROM EMP WHERE ENAME = 'SCOTT');
```

> ✅ 子查询可以放在 `WHERE` 后面，作为查询条件。

---

### 2. 放在 `FROM` 后面作为临时表

#### 示例 2：查询每个部门薪资在 1000-3000 之间的员工人数

```sql
-- 方法 1：直接过滤后分组
SELECT DEPTNO, COUNT(1)
FROM EMP
WHERE SAL BETWEEN 1000 AND 3000
GROUP BY DEPTNO;

-- 方法 2：使用子查询作为临时表
SELECT DEPTNO, COUNT(1)
FROM (
    SELECT * FROM EMP 
    WHERE SAL BETWEEN 1000 AND 3000
)
GROUP BY DEPTNO;
```

> ✅ 子查询可以作为临时表使用，嵌套在 `FROM` 后面。

---

### 示例：查询总工资高于 10000 的部门个数

```sql
SELECT COUNT(1) FROM (
    SELECT DEPTNO, SUM(SAL) 总工资
    FROM EMP
    GROUP BY DEPTNO
)
WHERE 总工资 > 10000;
```

---

### 示例：查询人数大于 3 的部门的所有员工信息

```sql
-- 步骤 1：找出人数大于 3 的部门编号
SELECT DEPTNO
FROM EMP
GROUP BY DEPTNO
HAVING COUNT(1) > 3;

-- 步骤 2：查询这些部门的员工信息
SELECT * FROM EMP
WHERE DEPTNO IN (
    SELECT DEPTNO
    FROM EMP
    GROUP BY DEPTNO
    HAVING COUNT(1) > 3
);
```

---

## 子查询的使用方式总结

| 使用位置 | 说明 |
|----------|------|
| `WHERE` 后面 | 用于过滤条件，通常返回单列 |
| `FROM` 后面 | 作为临时表，可进行多字段查询 |
| `HAVING` 中 | 用于对聚合结果进一步过滤 |
| `SELECT` 列中 | 返回单个值作为查询列（较少使用） |

## 练习题

### 练习 1：查询跟 `SCOTT` 工作相同的员工信息

```sql
-- 查出 SCOTT 的工作
SELECT JOB FROM EMP WHERE ENAME = 'SCOTT';

-- 查询工作相同但不是 SCOTT 的员工
SELECT * FROM EMP
WHERE JOB = (
    SELECT JOB FROM EMP WHERE ENAME = 'SCOTT'
)
AND ENAME <> 'SCOTT';
```

---

### 练习 2：查询平均工资高于 2000 的部门中，薪资高于 2000 的员工信息

```sql
-- 查出平均工资高于 2000 的部门
SELECT DEPTNO
FROM EMP
GROUP BY DEPTNO
HAVING AVG(SAL) > 2000;

-- 查询这些部门中工资高于 2000 的员工
SELECT * FROM EMP
WHERE DEPTNO IN (
    SELECT DEPTNO
    FROM EMP
    GROUP BY DEPTNO
    HAVING AVG(SAL) > 2000
)
AND SAL > 2000;
```

---

### 练习 3：查询部门人数大于 3 的部门中，薪资最高的员工信息

```sql
-- 查出人数大于 3 的部门
SELECT DEPTNO
FROM EMP
GROUP BY DEPTNO
HAVING COUNT(1) > 3;

-- 查出这些部门中的最高薪资
SELECT MAX(SAL)
FROM EMP
WHERE DEPTNO IN (
    SELECT DEPTNO
    FROM EMP
    GROUP BY DEPTNO
    HAVING COUNT(1) > 3
);

-- 查询薪资等于最高薪资且属于人数大于 3 的部门的员工
SELECT * FROM EMP
WHERE SAL = (
    SELECT MAX(SAL)
    FROM EMP
    WHERE DEPTNO IN (
        SELECT DEPTNO
        FROM EMP
        GROUP BY DEPTNO
        HAVING COUNT(1) > 3
    )
)
AND DEPTNO IN (
    SELECT DEPTNO
    FROM EMP
    GROUP BY DEPTNO
    HAVING COUNT(1) > 3
);
```

---

## 子查询使用注意事项

- 子查询必须用括号 `()` 包裹。
- 子查询不能出现在同一层查询的关键字之后两次（如多个 `SELECT`）。
- 若子查询返回多行结果，主查询中应使用 `IN` 而非 `=`。
- 子查询可以嵌套多层，但建议保持逻辑清晰，避免过深嵌套。
- 子查询性能取决于数据量和索引，合理使用可提升效率。
