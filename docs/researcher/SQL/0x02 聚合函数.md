# 聚合函数

将多条数据合并成一个结果集。

## 聚合函数的种类：

| 函数名 | 说明           |
|--------|----------------|
| `MAX()`| 求最大值       |
| `MIN()`| 求最小值       |
| `SUM()`| 求和           |
| `AVG()`| 求平均数       |
| `COUNT()`| 计数         |

---

### 示例：求员工表中最高薪，最低薪，总薪资，薪资平均数

```sql
SELECT MAX(SAL), MIN(SAL), SUM(SAL), AVG(SAL)
FROM EMP;
```

> ⚠️ 注意：聚合函数的括号里面需要加字段（需要知道根据什么字段进行聚合）

---

### 查询公司总人数

```sql
SELECT COUNT(EMPNO) FROM EMP;  -- 计数员工编号
```

#### 更详细的计数示例：

```sql
SELECT 
    COUNT(EMPNO) 员工编号计数,
    COUNT(1) "1",  
    COUNT(*) "*",  
    COUNT(COMM) 存在空值的计数  
FROM EMP;
```

> ⚠️ 如果别名是纯数字或特殊符号开头，需要用双引号包裹，例如 `"1"`。

---

### 面试常问：`COUNT(字段)`、`COUNT(1)`、`COUNT(*)` 的区别

| 类型             | 说明 |
|------------------|------|
| `COUNT(1)`       | 统计总条数，空值也参与计算 |
| `COUNT(*)`       | 统计总条数，空值也参与计算 |
| `COUNT(字段)`    | 仅统计非空字段值 |

> ⚠️ 执行性能：`COUNT(1) > COUNT(*) > COUNT(字段)`  
> 实际中数据库优化器通常会对 `COUNT(1)` 和 `COUNT(*)` 做优化，性能差异不大。建议根据习惯选择使用。

## GROUP BY 分组

### 示例：查询每个部门的总工资

```sql
SELECT DEPTNO, SUM(SAL) 总薪资
FROM EMP
GROUP BY DEPTNO;
```

> ✅ 先分组，再聚合。

### 示例：求每个部门、每个工种的总薪资

```sql
SELECT DEPTNO, JOB, SUM(SAL) 总薪资
FROM EMP
GROUP BY DEPTNO, JOB;
```

> ✅ 多字段分组时，字段之间用逗号分隔。

---

### 注意事项

#### 错误写法（未出现在 GROUP BY 中的字段不能出现在 SELECT 中）：

```sql
SELECT DEPTNO, JOB, SAL, SUM(SAL) 总薪资
FROM EMP
GROUP BY DEPTNO, JOB;  -- ❌ SAL 不是 GROUP BY 的表达式
```

> ✅ SELECT 后面只能是 GROUP BY 的分组字段 和 聚合函数。

## HAVING 子句

用于对聚合结果进行过滤。

### 示例：查询 10 号部门外每个部门的总薪资大于 10000 的部门

```sql
SELECT DEPTNO, SUM(SAL) 总薪资
FROM EMP
WHERE DEPTNO <> 10
GROUP BY DEPTNO
HAVING SUM(SAL) > 10000;
```

### 方法 2（不推荐）：

```sql
SELECT DEPTNO, SUM(SAL) 总薪资
FROM EMP
GROUP BY DEPTNO
HAVING DEPTNO <> 10 AND SUM(SAL) > 10000;
```

> ✅ 方法 1 更高效，因为先用 `WHERE` 过滤数据，再进行分组聚合。

---

### HAVING 与 WHERE 的区别

| 对比项 | WHERE | HAVING |
|--------|-------|--------|
| 可以过滤字段 | ✅ | ✅（分组字段） |
| 可以过滤聚合值 | ❌ | ✅ |
| 可以过滤未分组字段 | ✅ | ❌ |

---

### 示例：查找每个部门除经理外员工的总薪资，并找出总薪资大于 6000 的部门

```sql
SELECT DEPTNO, SUM(SAL) 总薪资
FROM EMP
WHERE JOB <> 'MANAGER'
GROUP BY DEPTNO
HAVING SUM(SAL) > 6000;
```

---

### 示例：查询相同年份入职的不同工作的平均薪资，并过滤掉工作为 ANALYST 的记录，平均工资高于 2000

```sql
SELECT 
    TO_CHAR(HIREDATE, 'YYYY') 年份,
    JOB 工作,
    AVG(SAL) 平均薪资
FROM EMP
WHERE JOB <> 'ANALYST'
GROUP BY TO_CHAR(HIREDATE, 'YYYY'), JOB
HAVING AVG(SAL) > 2000;
```

## 综合练习

### 1. 查询人数大于 5 的部门编号、总工资、平均工资、人数

```sql
SELECT DEPTNO, SUM(SAL), AVG(SAL), COUNT(EMPNO)
FROM EMP
GROUP BY DEPTNO
HAVING COUNT(EMPNO) > 5;
```

---

### 2. 查询 10 号部门外最高工资高于 2000 的部门及相应最高薪资

```sql
SELECT DEPTNO, MAX(SAL)
FROM EMP
WHERE DEPTNO != 10
GROUP BY DEPTNO
HAVING MAX(SAL) > 2000;
```

---

### 3. 查询人数大于 3 的岗位，且岗位不为 CLERK

```sql
SELECT JOB
FROM EMP
WHERE JOB != 'CLERK'
GROUP BY JOB
HAVING COUNT(1) > 3;
```

---

### 4. 查询员工奖金的最大值、最小值、平均值、总数

```sql
SELECT 
    MAX(COMM),
    MIN(COMM),
    AVG(COMM),
    SUM(COMM)
FROM EMP;
```

> ⚠️ `NULL` 值不会参与聚合函数的运算，如需处理可使用 `NVL`：

```sql
SELECT 
    MAX(NVL(COMM, 0)),
    MIN(NVL(COMM, 0)),
    AVG(NVL(COMM, 0)),
    SUM(NVL(COMM, 0))
FROM EMP;
```

## SQL 执行顺序

| 阶段 | 关键字 | 说明 |
|------|--------|------|
| 1    | `FROM`     | 定位表 |
| 2    | `WHERE`    | 筛选行 |
| 3    | `GROUP BY` | 分组 |
| 4    | `HAVING`   | 过滤聚合结果 |
| 5    | `SELECT`   | 展示列 |
| 6    | `ORDER BY` | 排序结果 |

> ✅ `ORDER BY` 后面只能是 `GROUP BY` 的字段或聚合函数。

---

## 总结

- 使用 `GROUP BY` 进行分组统计时，`SELECT` 中只能包含分组字段和聚合函数。
- `WHERE` 用于过滤原始数据，`HAVING` 用于过滤聚合后的结果。
- `ORDER BY` 的字段必须是 `SELECT` 中的字段。
- 熟练掌握聚合函数与分组查询，是进行复杂统计分析的基础。
