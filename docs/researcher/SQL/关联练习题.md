```markdown
## 1. 查出最低工资大于1000的部门名称和部门的最高工资，平均工资，按部门降序，最高工资升序排列

```sql
SELECT T1.DEPTNO, T2.DNAME, MAX(SAL) AS MAX_SAL, AVG(SAL) AS AVG_SAL
FROM (SELECT DEPTNO, SAL FROM EMP WHERE DEPTNO IN (SELECT DEPTNO FROM EMP GROUP BY DEPTNO HAVING MIN(SAL) > 1000)) T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
GROUP BY T1.DEPTNO, T2.DNAME
ORDER BY T1.DEPTNO DESC, MAX(SAL) ASC;
```

## 2. 查出在不同地区的每种岗位的人数，最高工资，最低工资

```sql
SELECT T2.LOC, T1.JOB, COUNT(1) AS COUNT, MAX(SAL) AS MAX_SAL, MIN(SAL) AS MIN_SAL
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
GROUP BY T2.LOC, T1.JOB;
```

## 3. 查出员工的姓名，工资，工资等级，所在部门编号，部门名称，工作地点

```sql
SELECT T1.ENAME, T1.SAL, T3.GRADE, T2.DEPTNO, T2.DNAME, T2.LOC
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
LEFT JOIN SALGRADE T3 ON T1.SAL BETWEEN T3.LOSAL AND T3.HISAL;
```

## 4. 查询出工资高于部门30中任意一名员工工资的员工的姓名，工资，部门名称，岗位

```sql
SELECT T1.ENAME, T1.SAL, T2.DNAME, T1.JOB
FROM (SELECT ENAME, JOB, SAL, DEPTNO FROM EMP WHERE SAL > (SELECT MAX(SAL) FROM EMP WHERE DEPTNO = 30)) T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO;
```

## 5. 查询出部门最高工资在 2500~3000的部门的所有员工的岗位，所在部门名称，上班地点以及工资等级

```sql
SELECT T1.DEPTNO, JOB, ENAME, DNAME, LOC, GRADE
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
LEFT JOIN SALGRADE T3 ON T1.SAL BETWEEN T3.LOSAL AND T3.HISAL
WHERE T1.DEPTNO IN (SELECT DEPTNO FROM EMP GROUP BY DEPTNO HAVING MAX(SAL) BETWEEN 2500 AND 3000);
```

## 6. 查出工作地点在 CHICAGO 的员工人数，最高工资，最低工资，平均工资

```sql
SELECT COUNT(1) AS COUNT, MAX(SAL) AS MAX_SAL, MIN(SAL) AS MIN_SAL, AVG(SAL) AS AVG_SAL
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
WHERE LOC = 'CHICAGO';
```

## 7. 查出各工资等级的员工的人数，最高工资和最低工资

```sql
SELECT T2.GRADE, COUNT(1) AS COUNT, MAX(SAL) AS MAX_SAL, MIN(SAL) AS MIN_SAL
FROM EMP T1
LEFT JOIN SALGRADE T2 ON T1.SAL BETWEEN T2.LOSAL AND T2.HISAL
GROUP BY T2.GRADE;
```

## 8. 分别使用子查询和关联查询的方式查出部门表哪个部门没有员工

- **子查询**

```sql
SELECT DEPTNO FROM DEPT WHERE deptno NOT IN (SELECT DEPTNO FROM EMP GROUP BY DEPTNO);
```

- **表关联**

```sql
SELECT T1.DEPTNO
FROM DEPT T1
LEFT JOIN EMP T2 ON T1.DEPTNO = T2.DEPTNO
WHERE EMPNO IS NULL;
```

## 9. 查询出工作地点不在 DALLAS 或者 部门名称不是 RESEARCH 的员工的姓名，工资，上班地点，工资等级

```sql
SELECT ENAME, SAL, LOC, GRADE
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
LEFT JOIN SALGRADE T3 ON T1.SAL BETWEEN T3.LOSAL AND T3.HISAL
WHERE T2.LOC <> 'DALLAS' AND T2.DNAME <> 'RESEARCH';
```

## 10. 查询部门名称为 SALES 或者工作地点在NEW YORK 的员工的姓名，工作，工资，部门编号，部门名称

```sql
SELECT ENAME, JOB, SAL, T1.DEPTNO, DNAME
FROM EMP T1
LEFT JOIN DEPT T2 ON T1.DEPTNO = T2.DEPTNO
WHERE DNAME = 'SALES' OR LOC = 'NEW YORK';
